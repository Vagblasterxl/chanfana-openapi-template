# Image Assets

Generated via `mcp-imagen` (Google Imagen 3) or `mcp-gemini` (creative editing).

## Generation
- Templates: `templates/images/standard-formats.yml`
- Formats: hero-banner (16:9), social-post (1:1), og-image (1.91:1), portrait (3:4)
- Use `mcp-gemini` for iterative editing, style transfer, or text-in-image

## Naming
`{descriptive-name}-v{version}.png` (e.g., `hero-sunset-v2.png`)

## Sidecar
Every image must have a `.meta.yml` with dimensions in the output block.
